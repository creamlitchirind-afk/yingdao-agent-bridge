# 操作能力训练与验收

训练是从真实任务中更新规则、案例和验证代码，不是训练模型权重。状态分为：资料已查、计划预检、影刀实跑、业务核验。不能从其中一级推断下一级。最新结果见 TRAINING_RESULTS.md。

2026-10-29补充：原生网页元素、关联行、翻页等待、break、剪贴板和键盘前台写入已有[商城案例](SHOP_ORDERS.md)的限定范围实测。下方三例保留其原JS/表达式实现，不把它们重写成未运行的原生案例；Word、图像和任意Excel行列编辑仍待独立验证。

## 执行仓库案例

运行 `python examples/operation_training.py prepare --directory <全新绝对目录>`。只生成虚构本地网页和三个计划，不操作影刀。
使用专用应用，确认无其他助手编辑；执行 bridge current/bind，再 create-flow 得到真实ID。每个案例独立新流程。把计划flow_id改为该ID，依次 preflight、build、inspect、run。out参数training_result是实际验收数据，保存运行响应和run_id。提取真实输出值为JSON文件，再执行 `python examples/operation_training.py verify --directory <目录> --case <案例> --actual <实际值JSON>`。不得把expected复制为实际值。

构建器对嵌套结束标记的处理必须现场检查；插入返回错误也可能已改变流程，先回读，不重插。API、Python、影刀版本及每个失败请求保存在本地证据中，不把账号和绝对私有路径发布到仓库。

网页案例运行前，在单独终端执行 `python examples/operation_training.py serve --directory <生成目录>`，仅监听127.0.0.1:18765；结束后Ctrl+C关闭。端口占用则用`--port`选择空闲端口，并同步更改计划URL或生成时传`--web-base-url`。不需要外网。浏览器扩展未获本地文件权限时file://会失败，使用此回环HTTP服务，不修改用户浏览器权限。

## 各模块练习及边界

|模块|练习|通过标准与扩展项|
|---|---|---|
|判断与循环|logic：原生forin、if、endloop筛选0/小数/正数|结果[0.5,2,3,1]，合计6.5；此例不能代表二分支、多分支、嵌套全部通过|
|等待|file_wait_regex：文件创建后等待存在、固定短等待|等待结果True；未测超时、随机等待和异步出现，不声称已覆盖|
|网页|web_local：打开本地网页、修改阈值、触发筛选、读取结果、仅关闭自身网页|结果A/C；通过浏览器JS操作DOM，不等于验证原生元素捕获/关联元素/鼠标点击|
|Excel|已有sheet_records及考勤示例；新增任务按读取→循环→判断→写入构建|比较实际数据、数值类型、表头、源哈希；复制粘贴、插删行列需独立案例，不能从单元格写入推断|
|文件与正则|file_wait_regex：原生读写文件，变量表达式用Python re提取|ORDER A102和QTY 3；明确正则采用表达式而非原生正则指令|
|PDF|已有pdf_orders固定文本PDF案例|逐字段核验；扫描件OCR不在原案例范围|
|Word|后续用虚构文档验证段落/表格填充和另存为|内容与格式分开核验，不能从PDF通过推断Word能力|
|鼠标、键盘、图像|后续专用测试窗体：输入文本、点击按钮、识图等待|先确认窗口/分辨率/焦点，仅操作测试窗口；不能只用屏幕坐标在任意窗口点击|
|剪贴板|后续独立测试文本往返|保存原值并还原；涉及文件/图片剪贴板时不能用文本覆盖代替恢复|
|AI应用|让Kunar输出结构化字段，再用确定性规则核验|缺失/歧义进入待确认；不能用模型自评代替实际输入输出验证|

## 下批逻辑与界面案例

- 二分支/多分支：0、0.5、2、3、缺失输入覆盖全部路径；比较分支标签。
- 嵌套循环：两学院各两班，核验笛卡尔遍历顺序及计数，变量不复用覆盖。
- for/while：核对边界包含性；continue跳过指定项，break到达条件退出。
- 无限循环只在带独立次数上限、超时和退出条件的测试流程中验证。
- 等待超时：等待一个确定不出现的测试标记，核验实际超时分支；不以固定sleep代替条件等待。
- 原生网页元素：在本地inventory页面捕获输入框/按钮、关联表格行，验证筛选后重新定位。元素句柄变化后重新获取。
- Excel行列：含公式、合并、样式的小副本；插入/删除后核验数据位置、公式引用和合并范围，源哈希不变。

每轮保存：用户任务、资料来源、前后快照、真实请求与响应、run_id、输出核验、失败与修复及Skill改动。任意未运行项目保持待验证。
