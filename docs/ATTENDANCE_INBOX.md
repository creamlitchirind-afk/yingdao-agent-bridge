# 按周目录导入与版本留存

入口：`examples/attendance/inbox.py --base <工作区>`，由影刀代码流程调用。它包装现有完整考勤引擎，不是四列筛选示例，也不自动创建影刀流程。

工作区含 `基础模板/01_起始总表`、`基础模板/课时分组.json`、`本周周表/第一周/考勤表` 与 `晚点名`。其他周同结构；收到哪个周就放对应周，按周顺序处理全部待导入目录。当前支持1至10周，要求从第一周连续累计。

每周生成独立的 `总表版本/<周次_时间_随机编号>`，包含材料快照、结果和导入记录。核验逐人数据、排序、状态、备注和合并后，原子更新当前版本指针，再更新 `当前总表/最新总表.xlsx`，最后把输入目录标记为 `-已导入`。发布与目录改名之间中断时，重启先恢复归档。不覆盖历史版本。Windows文件锁防止同一工作区并发运行。

对已导入周的更正暂不支持；缺周、重复周目录、空材料、未知周目录或输入运行中改变时明确报错。保留已有固定学院/表结构/学期限制。勿将目录版本机制描述为适配任意Excel。

测试：`python -m unittest discover -s tests -p test_attendance_inbox.py -v`。覆盖逐周累计、发布后改名中断恢复、无待处理时不重复、历史版保持、缺周和处理失败保护。
