## 未覆盖与限制

- 未在第二台干净电脑或其他影刀版本现场运行；同机隔离目录安装验证不能替代跨电脑验证。
- 官方账号类型、付费权益和模型服务可用性未做完整矩阵测试，项目不承诺所有账号可用或零费用。
- 只验证顺序流程和固定数据样例；通用网页、扫描 PDF、任意表格版式及嵌套控制逻辑不是本次已交付的通用能力。
- 运行前快照不是完整应用备份，没有自动回滚全部业务副作用的能力。
- 不支持多个助手并发修改；app.save 会保存整个应用，须使用专用应用。
- Kunar 此次测试明确指定技能和固定例子；没有据此宣称任意模糊自然语言都能稳定生成正确自动化。

本地详细证据在 `.local/state` 与 `.local/kunar-validation`，包含机器路径和账号相关绑定信息，因此不随源码包发布。
# 0.2.0 考勤样例验证（2026-10-21）

本机原型通过影刀执行三周汇总，逐人独立核对与重复导入检查通过；最新双材料报送规则下第三周缺晚点名且无违纪的学院已排在最后、合并红字未及时报送。运行日志含个人路径，不随仓库发布。

公开材料已替换学校、学院、班级和邮箱。公开版Python命令在隔离模式 `-I` 下运行三周，得到80/94/89名周异常学生、162/176.5/145学时；累计124人、483.5学时。14项单元/集成测试通过，包括同堂/跨堂折算、78份样例整套处理、缺报位置与合并、重复导入不变。

公开版安装器基于同机已用的代码流程接口整理，只创建并保存新流程。公开安装器在其他电脑/账号中的影刀现场执行尚未验证；公开版CLI本地处理验证不等同于该现场验证。以下0.1版记录保留为历史验证。
